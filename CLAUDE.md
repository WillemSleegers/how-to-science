This is a documentation/teaching site about research methodology and statistics, built on **Astro** with **Quarto** for code-heavy pages. It provides concise, reviewed summaries of methods and statistical topics (survey design, measurement/scales, meta-analysis, factor analysis, translation, etc.), plus concrete tutorials for applying them.

Work within the permissions already granted in `.claude/settings.json`. Only ask for additional permissions if the task genuinely cannot be accomplished within existing ones.

When a content page has both `index.qmd` and `index.md`, the `.qmd` is the source. Always edit the `.qmd`, never the `.md`.
